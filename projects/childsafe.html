Overview

Most safety benchmarks assume an adult user typing fixed prompts. ChildSafe instead runs a local open-weights probe model that talks like a child of a given developmental stage, with explicit runtime limits on vocabulary, memory and how conversations drift. The probe holds multi-turn conversations with the target system, and each full trace is scored on nine safety dimensions. Researchers can use the built-in developmental profiles, override selected parameters, or define their own.

Highlights

  • Across GPT-4o, Claude Sonnet 4 and Gemini 2.5 Pro, educational impact is consistently strong (≥ 0.95).
  • Long-term impact and boundary respect are the weakest dimensions for every model, the areas most in need of attention.
  • Gemini 2.5 Pro scores lowest on content appropriateness (0.56), well below GPT-4o (0.89) and Claude (0.88).
  • Vocabulary is constrained at generation time with logit masking, so the simulated child stays in character.

Results

How it works

  • ChildesLogitsProcessor: runtime logit masking for age-appropriate vocabulary.
  • DiscourseStateMachine: Markovian topic shifts instead of scripted dialogues.
  • Sliding context_horizon to model a child’s working memory.
  • Optional LLM-as-a-judge scoring with named or custom dimensions.
